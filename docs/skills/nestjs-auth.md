## Purpose

Sign-in, sessions, bearer tokens, API keys and permissions with the first-party `@nestjs/authentication` and `@nestjs/authorization` packages: timing-safe password checks, a global guard with `@Public()`, policies with `@Can()`.

## When it leads or supports

Supports `implement` on NestJS tasks that touch authentication or authorization.

## Use When

- Adding or changing authentication or authorization in a NestJS application.
