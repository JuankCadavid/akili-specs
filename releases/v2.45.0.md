# v2.45.0 - AKILI-SPECS methodology update

Release date: 2026-11-19

### Added

- **`ai-agent-development` 1.1 gains `references/guardrails.md` and `references/evals.md`, and the commands use them for AI agent specs.** `/akili-specify` records `AI Agent: yes` or `AI Agent: no` on every spec; when `yes`, `requirements.md` gains **Guardrails** and **Evals** sections, `design.md` an eval seam and an online monitoring plan, and `tasks.md` an eval-gate task. `/akili-test` runs an agent eval suite over the offline, regression and guardrail sets, stops when the eval-gate task has no runnable command, and adds an **Agent Evals** section to the report. `/akili-validate` applies an agent eval gate: a missing eval-gate task or results, a guardrail violation, a missed threshold or a missing online monitoring plan is a FAIL; a triggered no-pass condition is BLOCKED. A spec without `AI Agent: yes` gets none of this.

- **Modern Web Guidance (MWG) is admitted as an environment-provided supporting skill for web UI tasks.** It is Google Chrome's platform-implementation skill, licensed Apache-2.0 (`GoogleChrome/modern-web-guidance`). AKILI references it and never vendors, copies or installs it: `akili install` ships nothing of it and `akili doctor` checks none of it. It is never a lead; Impeccable still leads direction, page mode and craft. AKILI-SPECS is not affiliated with Google or the MWG project. `docs/skills/impeccable-bridge.md` gains a *Modern Web Guidance* section, and `docs/overview.md`, `docs/cli.md` and the `AGENTS.md` *Design Skills* list name it.
- **MWG is reached only through three selectors, never through a skills list.** They are a web UI task whose `Design route:` line says `platform mwg`; the same spec's `/akili-test` and `/akili-validate` re-read of the guide ids that task recorded; and the typed `/akili-audit modern-web` mode. A spec with no web UI task is unchanged in behavior. The rules live once in `impeccable-bridge/references/modern-web.md`; `/akili-specify`, `/akili-test`, `/akili-validate` and `/akili-propose` carry pointer lines.
- **Every AKILI-directed call passes a six-state gate and an exact-version pin.** The states are `missing`, `node < 22`, `consent needed`, `declined`, `ready` and `call failed`, each with a `MWG — …` report line. MWG needs Node 22 or newer and your consent, and the consent question names the npm fetch, the local run and Google usage telemetry. No state stops, fails or blocks a task, test, validation or audit; every state except `ready` lets the step finish without MWG. AKILI's default pin is `1.0.1`; a project overrides it with `pin <x.y.z>` in the Skill Map MWG row, and no call uses `@latest`. Every call sets `ENABLE_FILE_LOGGING=false`, and `DISABLE_TELEMETRY=1` unless you opted in to telemetry.
- **`/akili-audit modern-web [<path>]` is an opt-in, report-only scan.** It runs only when you type the mode, through MWG's `legacy-scan`, and writes `docs/specs/audits/modern-web-<YYYY-MM-DD>[-<safe-branch>][-N].md`. That file is never a drift report. `/akili-propose` accepts it as a requirement source, and its findings never become tasks of a running spec.
- **A web UI task's `Design route:` line gains a `platform` field, and `/akili-constitution` can offer a Skill Map row.** `design-routing.md` also gains an MWG expertise card and a *Platform guidance* step in the Build route. `/akili-constitution` Step 8D can write an MWG Skill Map row for a project with a browser-rendered UI, after asking you; the row is an availability and pin note, never a skill to assign.
- **The security record covers MWG `1.0.1` only.** The review, at tag `v1.0.1` (commit `64a6d708`), gave the verdict `PASS`, on the condition that the handling in `docs/skills/impeccable-bridge.md` stays in place. The `legacy-scan` bundle was traced from its entry point, not read line by line, and the Windows call form is unverified. The page cites upstream's eval figures and its stewardship claim to the upstream README at `v1.0.1`, as upstream's own statements that AKILI has not verified.
- **Install routes are printed for you to run, and AKILI never runs them.** They are upstream's routes from its README at `v1.0.1`: verified at the pin for Claude Code, Codex and Antigravity, and unverified for Cursor and OpenCode.
- **`test/modern-web-guidance.test.js` pins these clauses to the shipped files.** It runs no MWG code and makes no network call.

### Changed

- **`docs/skills/governance.md` rule 4 names three selectors, with a per-selector outcome.** A spec whose `Deliverable` selects an environment-provided skill still stops at that skill's availability gate. A web UI task's `platform mwg` route and the typed `/akili-audit modern-web` mode never stop: they continue without MWG and report `not run`. `docs/flow.md`, `docs/skills/README.md`, `docs/skills/video-production.md`, `docs/overview.md`, `docs/cli.md` and `AGENTS.md` restate it.
- **`ai-agent-development` is now `conditional`, not `stack`.** `/akili-constitution` Step 5 loads it when the product includes an AI agent, instead of listing it through the Step 8D Skill Map; `docs/skills/governance.md`, `AGENTS.md` and the backend routing matrix say so.

- **`akili-panel` is 1.1.1.** Its `plugin.json` `description` named only the `Next` button; it now lists the methodology flow, active branch, token use, session model, collapsible `Skills` list and small `AKILI` title. In `flow.mjs`, `SKILL_CATALOG` lists `ai-agent-development` as `conditional`, not `stack`, so the pane's `Skills` list shows it in the `conditional` group. The plugin version moves from `1.1.0` to `1.1.1` so marketplace installs pick up both changes.
- **Three Kaizen standardizations from earlier specs (PR #144).** The Tester persona's *Prove Behavior* section (`.claude/templates/tester.md`, section marker now `since=v2.45.0`) adds: a test helper that bounds a text range by start and end anchors fails when either anchor is not found, never falling back to the end of the file. `/akili-specify` adds *Phase-scoped gates*: when a requirement makes more than one phase gate refuse on missing items, each gate names only the items its own phase produces. `docs/skills/governance.md` *Attribution complete* adds that a third-party skill's admission review quotes its scan commands verbatim, reads a scanner exit status of 2 as "not run", and runs hidden-character checks with a tool that supports the pattern on the host.
- **`docs/plugins/akili-panel.md` names the versions 1.1.0 was tested on.** It said the tests ran on 2.1.319 (1.0.0); 1.1.0's plugin tests ran on 2.1.318 and 2.1.322. The 2.1.318 minimum is unchanged.
- **The package `description` and the README lead with the brand descriptor ("AI agents and software").** The README adds it as one line under `# AKILI` and keeps the tagline; the `description` keeps a short explanation after it. Copy only.
