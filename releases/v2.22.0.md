# v2.22.0 - AKILI-SPECS methodology update

Release date: 2026-08-10

### Added

- **`ai-agent-development` — a new original-authorship `stack` skill giving agents the decision layer for building AI agents (release classified minor: a new skill is new capability).** It answers *what to build an agent with and how to shape it*, and operates nothing: a thin `SKILL.md` router (scope and composition contract, a three-question routing heuristic — where it runs, how much orchestration control, what must survive restarts and where humans intervene — plus the runtime deferral table and a maturity note) over four `references/` files loaded per task: `framework-selection.md` (dated matrix over LangGraph, Deep Agents, LangChain, Bedrock AgentCore, and the Claude Agent SDK, with CrewAI and AutoGen at recognition level — AutoGen's row records its succession by the Microsoft Agent Framework), `langgraph-patterns.md` (state design, authored graph vs prebuilt loop, durable execution, interrupts, failure routing, streaming, memory, subgraphs — each with when it is warranted and when it is overkill), `akili-spec-mapping.md` (agent behaviors and guardrails as `requirements.md` scenarios, graph/state/tools/memory/HITL points as `design.md` decisions, evals as `tasks.md` tasks with verification commands — carrying the rule that nondeterministic output needs an eval threshold with a stated no-pass clause, never a bare exit-0 test), and `aws-deployment.md` (AgentCore Runtime vs Lambda vs ECS for agent workloads, hosting *choice* only). Runtime detail defers outward by design — `amazon-bedrock` for Bedrock/AgentCore operation, `claude-api` for the Anthropic SDK and MCP, `aws-serverless` for Lambda/ECS/API Gateway implementation, pinned official docs for framework APIs — and because availability is per-developer, every route names its docs substitute so the skill stands alone. Every factual claim cites an official-docs link, every reference carries a `## Sources` block of pinned links, the three ecosystem-facing references — framework selection, LangGraph patterns, and AWS hosting — additionally carry a `Last verified:` date, and unvalidated guidance is marked with a greppable `> Unvalidated:` marker rather than omitted. Wiring stays governance-compliant: the skill is never load-directed in command text, appearing only as a candidate in `/akili-constitution`'s Step 5 TRD bootstrap list and Step 8D Skill Map builder pool and in `/akili-specify`'s Step 2.1 no-map fallback list, and reaching agents through the project `## Skill Map`. Inventory closed in the same change: `docs/skills/ai-agent-development.md`, the `docs/skills/README.md` row, the `docs/skills/governance.md` `stack` assignment, the `docs/commands/akili-constitution.md` mirror, and the README skill list.

### Changed

- **npm tarball no longer ships `docs/specs/`** (internal spec working documents — execution logs, judgments, validation reports). `package.json` `files` gains `!docs/specs`; user-facing docs under `docs/` are unaffected. Surfaced by the first committed spec folder during `changes/ai-agent-development-skill` validation.
- **Claude Design MCP added as the mockup fallback when Stitch MCP is unavailable.** The `/akili-propose` Mockup Fallback chain is now Stitch MCP → Claude Design MCP (`claude-design`, registered with `claude mcp add --scope user --transport http claude-design https://api.anthropic.com/v1/design/mcp` + `/design-login`) → lightweight self-contained HTML mockup. The proposal's Visual Reference source enum gains `Generated mockup (claude-design)`, and `/akili-specify` reads Claude Design mockups directly from their exported HTML/screenshots (`stitch-design` remains the interpreter only for `.stitch` artifacts). Docs mirror updated (`docs/commands/akili-propose.md`).
